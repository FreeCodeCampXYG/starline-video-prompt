## 1. 从参考案例迁移控制语法

先看成片或画面，找到与目标效果最接近的单个镜头。不要复制整段提示词，只提取三类可复用句子：

- 摄影机如何运动、落位和跟焦。
- 人物按什么顺序动作与反应。
- 灯光从哪里来、如何塑造明暗和材质。

再替换人物、场景、动作和故事目的。参考图必须分工：身份图管脸与身材，服装图管材质，场景图管几何，动作/视频参考管运动。一个参考素材不应模糊地承担所有职责。

## 2. STAR × 二八法则

- `S`：用可见危机制造失衡，不用旁白解释问题。
- `T`：给角色一个有时间或代价压力的具体使命。
- `A`：用全片约 50% 篇幅表现观察、选择、行动、失败修正；这是领导力真正出现的位置。
- `R`：结果既要可见，也要保留选择的代价或责任，不做无条件胜利广告。

二八法则不是“20% 写短、80% 写长”：20% 锁定身份、位置、镜头轴、光向、材质和尾帧；80% 写按秒推进的可见因果。

## 3. 角色表演反应链

使用五拍反应链：

1. 保持刺激前状态。
2. 刺激到来，短暂停顿。
3. 角色试图压住情绪或维持身份。
4. 情绪从眼神、呼吸、手或重心泄露。
5. 用一个决定性动作收尾。

每拍选 2-4 个部位即可：

- 眼神：视线目标、停止眨眼、失焦、重新锁定。
- 面部：上下眼睑、眉间、鼻翼、嘴唇、下颌、咬肌。
- 身体：头部停顿、肩膀沉降、手指收紧/松开、胸口起伏、前倾/后退。
- 生理：喉头滚动、呼吸中断、膈肌痉挛、指节泛白、真实皮肤纹理。

摄影通过浅景深、前景遮挡、跟焦和情绪转变后的缓慢推进放大表演，但不能替代表演。

## 4. 第一帧与场面调度

提示词按需使用以下控制项：

```text
STYLE: film stock, contrast, texture, production method
FIRST FRAME: all required characters already visible in correct positions
CHARACTER: reference source of truth for identity and costume
POSITION: torso direction, gaze target, screen-left/right, distance
CAMERA: lens, height, move, operator settling, focus target
ACTION: one primary action per time block, strict sequence
PHYSICS: gravity, mass, inertia, friction, contact, weight transfer
LIGHTING: source direction, shadow side, practicals, exposure rule
CONTINUITY: screen direction, gaze, light, prop and body state
AUDIO: exact dialogue only, effects and silence; no ad-libs
TECHNICAL: fps, shutter, motion blur, aspect ratio
```

第一帧不要空等人物入场。连续镜头的上一镜尾帧必须明确成为下一镜的身份、构图和物体状态约束。

## 5. 复古科幻与大场面

原创复古太空史诗可使用：1970-80 年代模拟未来主义、实拍微缩模型、运动控制摄影、光学合成、磨损喷漆金属、钨丝实景灯、CRT 扫描质感、Kodak Vision3 500T 或类似具体胶片特性、自然颗粒、低调逆光和容积烟。

不要复制具体影视 IP。避免专有角色、飞船剪影、激光颜色组合、徽记、盔甲、对白、音乐旋律和标志性构图。建立原创阵营、原创舰船几何与原创道具语言。

大场面仍遵守一个主事件：例如“指挥官拒绝全自动攻击并把无人舰群拆成救援、护航、拦截三队”。舰队运动是决定的后果，不是无因爆炸。锁定敌我屏幕方向、相对速度、编队间距、命中来源、碎片方向和光源。

## 6. 审片清单

- 去掉旁白后，危机、使命、选择和结果是否仍然看得懂？
- 角色是否先反应再行动，而不是直接摆出情绪脸？
- 每拍微表演是否不超过 2-4 个有效细节？
- 摄影机是否知道在看谁、为什么此刻移动？
- 第一帧人物和位置是否完整，尾帧是否稳定并可接力？
- 道具与特效是否有重量、接触、惯性和可见原因？
- 大场面是否有明确空间轴和一个主因果？
- 风格是否来自材质、灯光、镜头和制作方法，而不是形容词？
- 是否避开可读乱码、虚构数据与具体影视 IP 相似元素？
