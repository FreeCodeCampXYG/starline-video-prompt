# AI 视频投稿合规门禁

本文件把用户提供的比赛口径整理为生成前检查与生成后复核。它只约束公开投稿交付，不改变原创故事的戏剧目标。

## 交付硬口径

- 内容必须是原创、完整、健康、表达清楚的 AI 参与创作视频。
- 系列剧每集 1–5 分钟；60 秒或更短版本只能标为预告/开场样片，不得冒充最终单集。
- 画幅 9:16 或 16:9，分辨率不低于 720P；单文件不超过 200MB。超过时准备高清交付版与 200MB 内审核版。
- 投稿信息需包含成片、作品名/简介、赛道、创作说明和 AI 工具使用说明。

## 禁止内容检查

交付前排除：国家标志、军队象征、标志性国家建筑、党政/国家机关形象；错误价值观、丧文化、拜金享乐、重男轻女、暴饮暴食；民族、宗教、性别、地域、国别、性取向、年龄或特殊人群歧视；重大舆情/时政/疫情等敏感事件；未授权真人、明星、英烈、历史人物、动漫角色、网络视频、声音或第三方素材；色情、性行为、性暗示、性爱喘息/呻吟、露点、低俗暴露、童婚、强暴、下药、出轨、小三上位、乱伦、耽美/四爱/变装/水仙、一孕多胎或男人生子；吸烟、烟草特写；血腥、恐怖暴力或可模仿的危险行为。

只在负面约束中提及上述风险，不等于内容合规。必须检查生成画面是否意外出现伪文字、品牌标识、角标、黑边、拉伸、二维码、链接、联系方式、广告或引流。

## 电气事故的安全改写

如果剧情需要开发板、液体或放电：使用未通电设备、绝缘工具、受保护的低压信号和非伤害性静电视觉；不得展示人体导电、裸露市电、可复现接线步骤、烧伤皮肤、伤口、血液或鼓励模仿的操作顺序。安全提示应放在导演说明/后期说明中，故事画面只保留必要因果。

## 名称、封面与片尾

- 投稿名称简洁、与内容强关联，使用简体中文，不加无关英文、编号、话题符号或特殊装饰。
- 封面不加黑边、不拉伸、不加高亮角标；不得色情、擦边、血腥、暴力或侵权。
- 片尾只保留主题表达或必要署名；不放链接、二维码、联系方式、广告、导流口令或平台外交易信息。

## 审片记录格式

按以下顺序复核并留证：结构/实际时长 → 剧情阶段与切点 → 身份/资产 → 空间/GEO/轴线 → 动作物理 → 表演/对白/口型 → 特效来源与终态 → 光线/材质/声音/画质 → 封面/名称/片尾/文件大小。

每个问题记录：等级（阻断/重要/优化）、时间码、可观察证据、问题维度、对剧情或投稿的影响、返修方向、保留项和验收标准。没有实际成片时，结论只能标为“文本预审”或 `missing evidence`。
